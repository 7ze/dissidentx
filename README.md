# DissidentX

DissidentX is a publishing platform for essays and ideas, built with AstroJS for fast, modern web performance, styled with Tailwind CSS for clean, responsive design, and enhanced with DaisyUI for streamlined UI components. It’s a space to share thought-provoking content with a focus on clarity and accessibility.
